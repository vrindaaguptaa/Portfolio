# Vrinda Gupta | Personal Portfolio

A personal portfolio website showcasing my projects, technical skills, background, and interests in web development and software engineering.

## 🌐 Overview

This portfolio serves as a digital introduction to my work, highlighting the projects I've built, technologies I've worked with, and my journey as a Computer Science Engineering student and developer.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Multi-page navigation
- Home, About, Projects, and Contact pages
- Light and dark theme toggle
- Interactive project showcase
- Responsive layouts using CSS
- Keyboard-friendly navigation
- Contact form with client-side validation
- Clean and minimal visual design

## 🛠️ Tech Stack

- **HTML5** — Structure and semantic markup
- **CSS3** — Styling, responsive layouts, animations, and themes
- **JavaScript** — Interactive functionality and DOM manipulation

## 💻 Running Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vrindaaguptaa/my-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd my-portfolio
   ```

3. Open the project in VS Code.

4. Run `index.html` using the Live Server extension.
